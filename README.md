# Meanwhile — Collaborative Study Companion

> _"For the things we're learning, and the people we're learning alongside."_

Meanwhile is a shared space for two people who study, work, or pursue personal goals from different places. It provides a quiet, literary environment inspired by Japanese stationery, cozy watercolor landscapes, and vintage botanical journals.

## Features

- **Quiet Editorial Design**: Calming paper palette, elegant serif typography, unobtrusive interactions.
- **Ambient Scenery**: 6 living illustrated backgrounds (Rainy Window, Countryside at Dusk, Spring Garden, Cloudy Seaside, Quiet Library, Dreamy Starry Night).
- **Study Notebook**: Intelligent deterministic parser for pasting unstructured notes, chapters, topics, durations, and notes.
- **Shared Presence & Delight**: Gentle pokes, real-time topic progress updates, mutual companion activity feed.
- **Quiet Room**: Distraction-free focus timer (25 min, 50 min, custom) with subtle ambient audio.
- **Little Journal**: Chronological narrative of completed topics and study milestones.
- **Collaboration**: Dual-mode architecture supporting instant offline/cross-tab demo sync as well as live Supabase database and authentication.
